# PES 2018 (Xbox 360, Europe) port

This branch carries a PES 2018 (Xbox 360, Europe) port on top of the
`pes2017-recomp` pipeline. It is a different title, not a patch to PES 2017:
the recompiler and the Android runtime are shared, while the title addresses,
hooks, switch tables and app identity are PES 2018's. How it should be
integrated (a separate repository or a title profile here) is a question for
the maintainer.

Status: on a Xiaomi 14T Pro (Dimensity 9300+, Mali-G720, Android 16) the APK
boots to the title screen and plays an Exhibition match at 60 FPS. It is not
a finished compatibility matrix: 70 kernel imports are still stubs, and the
other modes and save round-trips have not been exercised.

## Input

- A PES 2018 Xbox 360 Europe disc, `default.xex` (title `0x4A3007D3`, XEX
  version 16, image base `0x82000000`, entry `0x824366D8`). The disc's XDVDFS
  starts at `0x2080000`.
- The game data is about 7.3 GB (36 CPK archives and `nxeart`). No game data
  is committed; build from your own disc.

## Build

The steps are the same as PES 2017:

```bash
GAME=/path/to/folder-with-default.xex ./build.sh
```

- `RECOMPILE_ONLY=1` stops after the PPC → C++ pass.
- `DIAGNOSTICS=ON` builds the runtime with traces, dumps and reports.
- The APK packages the prebuilt arm64 library with
  `-PprebuiltNative=<stage>`.

The 2018 run converges with 0 jump-table errors, 44 undecodable words at the
tail of `.text`, and one unrecognized `mullhwu` (a data word inside `.text`;
the final 2017 image has the same single line).

## Title-specific changes

- `runtime/title.h`: entry point, D3D Present, BlockOnFence, the two aspect
  floats, and the two kernel import records.
- `runtime/pes_hooks.cpp`: fence-poll yield, Intro/ProcInstall state,
  procedure dispatcher, and two ring-kick hooks.
- `config/PES.toml`: 226 fixbounds entries plus 15 leaf functions reached only
  through a vtable (the vtable scan stops at a `blr`; these sit behind a tail
  `b`).
- `runtime/install/install.cpp`: title id `0x4A3007D3` and the 2018 XEX hash.
- Android: applicationId `com.pes2018.recomp`, label "PES 2018", 2018 icons
  and wordmark, and system-bar insets for the app's own screens (the game
  stays full screen).

## Known limitations

- 70 kernel imports are stubbed; 2018-specific code paths may need them.
- The Vulkan shader cache asset is still the 2017 one. It is validated by
  `pipelineCacheUUID` and size, so a mismatch is ignored.
- The in-app installer path from the 2018 ISO was not exercised end to end;
  the test pushed the files directly to the app folder.
- The 2018-specific first-run flow, save data and player data are unverified.
